# Abu Sufiyan — 3D Interactive Portfolio

A modern, highly interactive 3D web portfolio built with React and WebGL.

🌍 **Live Demo:** [https://portfolio-website-ten-theta-96.vercel.app/](https://portfolio-website-ten-theta-96.vercel.app/)

## Features
- **Immersive 3D Experience:** Smooth, scroll-driven 3D environments.
- **Lenis Smooth Scrolling:** Buttery smooth scroll physics natively integrated.
- **Interactive 3D Resume:** A unique standalone 3D paper rendering of my CV.
- **Responsive Design:** Optimized for both desktop and mobile viewing with perfect touch gesture support.

## Tech Stack
- React
- React Three Fiber / Three.js
- Tailwind CSS
- Vite

## Run Locally

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
